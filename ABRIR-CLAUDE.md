# Cómo comenzar

1. Abrí la aplicación **Claude**.
2. Entrá en la pestaña **Code**.
3. Seleccioná **Local**.
4. Elegí esta carpeta:

   `C:\Users\laule\Documents\Codex\2026-08-20\es\outputs\soporteqr`

5. Copiá en Claude el contenido de `PROMPT_INICIAL.md`.
6. Aceptá únicamente las acciones que ocurran dentro de esta carpeta.

Claude cargará automáticamente `CLAUDE.md`. La configuración permite ediciones y comandos comunes de desarrollo, pero bloquea secretos, despliegues, `git push`, publicaciones y operaciones destructivas.

## Requisitos detectados

- Node.js: instalado.
- npm: instalado.
- Git para Windows: instalado.
- Visual Studio Code: instalado.
- Claude Desktop: instalado.
- Docker: no instalado.
- Claude Code CLI: no instalado.

Podés trabajar desde la pestaña Code de Claude Desktop sin instalar la CLI. Docker será necesario para ejecutar PostgreSQL localmente con el flujo previsto.
